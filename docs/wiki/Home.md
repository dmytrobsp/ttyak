ttyak is a Slack client for the terminal, written in Rust: messages and threads, pictures and video, desktop
notifications and huddles. It is not an official Slack app. This wiki is its manual; the site is
[ttyak.sh](https://ttyak.sh), the code [github.com/dmytrobsp/ttyak](https://github.com/dmytrobsp/ttyak).
